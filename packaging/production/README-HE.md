# Sela (סלע) - גרסת Production

גרסה מוכנה להפעלה ולהדגמה. **אין צורך להתקין Node.js, Git, Yarn או כל תלות פיתוח, ואין צורך באינטרנט בזמן ההפעלה.** האפליקציה כבר בנויה (תיקיית `app`), והסקריפט מפעיל שרת קבצים סטטי קטן שמובנה ב-Windows PowerShell.

- תאריך בנייה: {{DATE}}, בבנייה נקייה מחבילת Sela-Source.zip של אותו commit, עם Node.js {{NODE}}.

- פרטים מלאים בקובץ `VERSION.txt`.

## מה כלול

- תקציב מעטפות, חשבונות, תנועות, תנועות קבועות ודוחות, בעברית מלאה (כולל מסך הטעינה). אפשר לעבור לאנגלית: הגדרות > שפה.
- קטגוריות מותאמות אישית (למשל "יש חסד").
- מחשבון משכנתא: מסלולי פריים, צמוד-מדד וקבועה; הצמדה חודשית למדד; שינויי פריים לפי חודש; טבלת מדד בהקלדה או בייבוא קובץ.
- שמירה, טעינה ומחיקה של תמהילים, ושמירה אוטומטית של העבודה הנוכחית.
- השוואה בין תמהילים, יחס החזר להכנסה, עלות ריבית ריאלית, מועד סילוק וגרף.
- ייצוא לוח סילוקין ל-Excel/CSV, הדפסה או שמירה כ-PDF, וגיבוי מלא של התקציב.

## דרישות מקדימות

- Windows 10 או 11 (Windows PowerShell 5.1, מגיע עם המערכת).
- Google Chrome או Microsoft Edge (נבדקו). דפדפנים אחרים לא נבדקו.
- כ-20MB דיסק, וכ-1GB זיכרון פנוי לדפדפן.
- פורט **3001** פנוי.

## הפעלה

1. לחלץ את ה-ZIP לתיקייה כלשהי (נתיב בעברית או עם רווחים מותר).
2. אחת משתי דרכים:
   - לחיצה כפולה על `start-sela-prod.cmd`, או
   - ב-PowerShell בתיקייה: `powershell -ExecutionPolicy Bypass -File .\start-sela-prod.ps1`
3. נפתח הדפדפן בכתובת **http://localhost:3001**. אם לא, פותחים ידנית. (בלי פתיחת דפדפן: להוסיף `-NoBrowser`.)
4. הטעינה הראשונה בדפדפן אורכת מספר שניות; הבאות מהירות יותר.

## סגירה

בחלון הטרמינל לוחצים `Ctrl+C` (או סוגרים את החלון). הנתונים נשמרים בדפדפן ולא נמחקים בסגירה.

## שמירת נתונים - חשוב

- הנתונים (חשבונות, תנועות, תקציב ותמהילי משכנתא) נשמרים **בדפדפן** שבו עבדתם, ולא בתיקיית התוכנה.
- הם קשורים לכתובת `http://localhost:3001`, לדפדפן ולפרופיל. דפדפן אחר, פרופיל אחר, מצב גלישה בסתר או כתובת אחרת (למשל `127.0.0.1`) יציגו תקציב ריק.
- מחיקת "נתוני אתרים" מהדפדפן תמחק את התקציב. **לפני הזנת נתונים אמיתיים מומלץ לגבות:** עוד > הגדרות > ייצוא נתונים. תמהילי המשכנתא השמורים נכללים בגיבוי.
- הפורט 3001 קבוע בכוונה, כדי שהכתובת תישאר זהה בין הפעלות. גרסת הפיתוח (`start-sela.ps1` בקוד המקור) משתמשת באותה כתובת ולכן באותם נתוני דפדפן.

## מגבלות ידועות

- חישובי המשכנתא הם הערכה לפי ההנחות שהוזנו, ואינם הצעת בנק או ייעוץ פיננסי.
- מדד ופריים מוזנים ידנית או מיובאים מקובץ; אין משיכה אוטומטית מהלמ"ס או מבנק ישראל.
- אין סנכרון בין מכשירים (מצב "אין שרת") ואין חיבור לחשבונות בנק.
- השרת מאזין ל-`localhost` בלבד: אי אפשר לפתוח את סלע מטלפון דרך הרשת. ההתאמה למסך צר נבדקה בגודל חלון.
- יש להשתמש בכתובת `localhost` בלבד (לא `127.0.0.1`).
- Windows בלבד (הסקריפט משתמש ב-PowerShell וב-HttpListener של Windows).

## תקלות נפוצות

| תקלה                                                            | פתרון                                                                                                                                             |
| --------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| "port 3001 is already in use"                                   | חלון Sela אחר כבר פועל (פתחו http://localhost:3001) או תוכנה אחרת משתמשת בפורט. סגרו אותה והפעילו שוב.                                            |
| הסקריפט נחסם ("running scripts is disabled")                    | להפעיל דרך `start-sela-prod.cmd` או עם `-ExecutionPolicy Bypass`. אם הקבצים נחסמו אחרי הורדה: קליק ימני על ה-ZIP, מאפיינים, Unblock, וחילוץ מחדש. |
| חלון חומת אש / אנטי-וירוס                                       | השרת מאזין רק ל-localhost, אין צורך לאשר גישה מהרשת.                                                                                              |
| הדף נתקע על מסך הטעינה ("מאתחל את החיבור למסד הנתונים המקומי…") | להשתמש ב-Chrome או Edge רגילים (לא בדפדפן מובנה בכלי אחר), לסגור תוכנות ולשוניות כבדות, ולרענן עם Ctrl+Shift+R.                                   |
| התקציב נעלם                                                     | כנראה דפדפן, פרופיל או כתובת אחרים, או מחיקת נתוני אתרים. שחזור מהגיבוי: הגדרות > ייבוא.                                                          |
| אחרי עדכון גרסה נראה המסך הישן                                  | לרענן בכוח (Ctrl+Shift+R); הגרסה החדשה נטענת בהפעלה הבאה.                                                                                         |
