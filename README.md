# סלע (Sela)

אפליקציה ללווי כלכלי של משפחות. היא נועדה בעיקר ליועץ הכלכלי שמלווה את המשפחה: לנתח את המצב, לבנות תוכניות ולהציג אותן למשפחה בצורה ברורה. בהמשך תינתן למשפחה גישה לתיק שלה, כדי למלא פרטים ולעקוב אחרי מה שנדרש ממנה.

הפרויקט בנוי על [Actual Budget](https://github.com/actualbudget/actual) (רישיון MIT) ומוסיף מודול משכנתא ישראלי (מסלולי שפיצר ועוד).

## הרצה

הוראות הורדה והרצה לתלמידים: [STUDENTS.md](STUDENTS.md)

פתרון תקלות ב-Windows: [SETUP-WINDOWS.md](SETUP-WINDOWS.md)

בקיצור (Windows, Node 22.18 ומעלה ו-Git מותקנים, בנתיב באנגלית):

```powershell
powershell -ExecutionPolicy Bypass -File .\start-sela.ps1
```

ואז לפתוח http://localhost:3001
