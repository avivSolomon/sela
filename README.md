# סלע (Sela)

אפליקציה ללווי כלכלי של משפחות. היא נועדה בעיקר ליועץ הכלכלי שמלווה את המשפחה: לנתח את המצב, לבנות תוכניות ולהציג אותן למשפחה בצורה ברורה. בהמשך תינתן למשפחה גישה לתיק שלה, כדי למלא פרטים ולעקוב אחרי מה שנדרש ממנה.

הפרויקט בנוי על [Actual Budget](https://github.com/actualbudget/actual) (רישיון MIT) ומוסיף מודול משכנתא ישראלי (מסלולי שפיצר ועוד).

## הרצה

הוראות הורדה והרצה לתלמידים: [STUDENTS.md](STUDENTS.md)

פתרון תקלות ב-Windows: [SETUP-WINDOWS.md](SETUP-WINDOWS.md)

בקיצור (Windows, Node 22.18 ומעלה (מומלץ 24 LTS) ו-Git מותקנים, בנתיב באנגלית):

```powershell
powershell -ExecutionPolicy Bypass -File .\start-sela.ps1
```

בהפעלה הראשונה הסקריפט מתקין את התלויות הדרושות ובונה את האפליקציה (כמה דקות), ובפעמים הבאות הוא מפעיל אותה תוך שניות על http://localhost:3001. שרת הפיתוח (איטי יותר, עם רענון אוטומטי) זמין עם `-Dev`, ובנייה מחדש בכוח עם `-Rebuild`.

## מה נוסף על Actual Budget

- **מחשבון משכנתא ישראלי:** תמהיל מסלולים (פריים, צמוד מדד, קבועה לא צמודה) בשיטת שפיצר, ריבית אפס, שינויי פריים, הצמדה למדד לפי טבלת מדד או הנחה שנתית, לוח סילוקין, עלות ריאלית, ושמירה וטעינה של תמהילים בתוך התקציב (נכללים בגיבוי). החישובים ב-`packages/loot-core/src/shared/mortgage.ts` ובדיקותיהם בצד.
- **ממשק בעברית כברירת מחדל:** כולל קטגוריות ברירת מחדל, "תנועות קבועות" (במקום "תזמונים") ויכולת להוסיף קטגוריות משלכם.
- **גיבוי וייצוא:** "ייצוא נתונים" (גיבוי מלא) ו"ייצוא כל התנועות (Excel / CSV)" עם עברית תקינה ב-Excel.
- **הפעלה מהירה:** בנייה חד-פעמית ושרת סטטי מובנה (טעינה של כמה שניות במקום כדקה בשרת הפיתוח).
